# 🚪 M3: Room API and CLI

**Goal:** one typed room API and complete command behaviour, built on the in-process bus and SQLite state.

**Status:** 61 of 95 PRD checklist items ticked. The 34 open items are listed at the end. Source: [M3 in the PRD](../prd/milestones/M3-room-api-and-cli.md).

## ✅ What shipped

| Area | What it does | Where it lives |
|---|---|---|
| 🏠 Room lifecycle | Opens the room with an exact lock diagnostic, runs migrations and recovery, and shuts down. Interactive and one-shot open modes. Commit-only no-wait sends resume at the next interactive open. | `crates/squad-core/src/room.rs` |
| 📜 History and feed | Backward paging with ascending results. Shared feed items keep their identities through lag recovery. | `crates/squad-core/src/room.rs` |
| 📊 Room state | Presence, scores, contest state, daily spend, and pending picks, projected in camelCase. | `crates/squad-core/src/state.rs` |
| ⌨️ CLI commands | The full command and global flag set, interactive startup, dispatch, and exit codes. | `crates/squad-cli/src/args.rs`, `crates/squad-cli/src/main.rs` |
| 📨 `send` | Submission with quotes, preflight output, request-scoped waiting, and labelled text or JSON lines. | `crates/squad-cli/src/send.rs` |
| 📤 Export | Room and contest export for all seven scopes, with `-o` and the offline `export_offline` read path. | `crates/squad-cli/src/export.rs`, `crates/squad-core/src/export/mod.rs` |
| 🗂️ Models | Resolved roster and judge selection, printed without opening the room. | `crates/squad-cli/src/models.rs` |
| 🩺 Doctor and bus log | Doctor checks, `--env` output, read-only accounting, and bus-log output with redaction. | `crates/squad-cli/src/doctor.rs`, `crates/squad-cli/src/buslog.rs` |
| 🔤 Banners | Shared banner rendering with the embedded FIGlet fonts. | `crates/squad-core/src/banner/` |

## 🧪 How it is tested

- **Room lifecycle and requests:** `crates/squad-core/tests/room_lifecycle.rs`, `room_requests.rs`, `room_history.rs`, `room_state.rs` and `room_feed.rs`.
- **Commands:** `crates/squad-cli/tests/commands.rs`, `send.rs`, `send_no_wait.rs`, `models.rs`, `doctor.rs`, `output.rs` and `export.rs`.
- **Export snapshots:** `crates/squad-core/tests/export.rs`, `room_export.rs`, `tournament_export.rs`, `census_export.rs` and `probe_export.rs`, all from committed fixtures.
- **Banners:** `crates/squad-core/tests/banner.rs` checks that rendering is deterministic.

## 🔓 Still open in the PRD

The 34 open items are mostly coverage for the four newer modes (census, crosscheck, survey and probe). They cover lifecycle fixtures, paging, state projection, and feed delivery under lag. The rest are older checks, such as stop-all, regeneration and contest-pick routing (`M3.P1.L2.T4`, `M3.P1.L2.T8`). Each item is listed with its owning test file in the PRD.
