# 🧱 M0: Foundations

**Goal:** a reproducible Rust workspace, one configuration contract read from the environment, and a working setup script.

**Status:** 50 of 51 PRD checklist items ticked after the 2026-11-26 evidence audit. The owner check-in remains open. Source: [M0 in the PRD](../prd/milestones/M0-foundations.md).

## ✅ What shipped

| Area | What it does | Where it lives |
|---|---|---|
| 🧩 Workspace | Six crates on edition 2024, with the toolchain pinned and `Cargo.lock` committed. | `Cargo.toml`, `rust-toolchain.toml`, `crates/*` |
| 🔧 Configuration | Every `SQUAD_*` setting: types, defaults, validation, and whether the value was set explicitly. Loads the environment file and applies process overrides. | `crates/squad-protocol/src/config.rs`, `crates/squad-protocol/src/constants.rs` |
| 🛠️ Setup script | Detects the platform, installs or reuses `rustup`, builds the release binary, runs `doctor`, and keeps an existing `.env`. Flags: `--yes`, `--runtime-only`, `--no-build`, `--help`. | `setup.sh` |
| 🔐 Logging | JSON tracing to a file, with credential redaction and span identities. | `crates/squad-cli/src/logging.rs` |
| 📄 Example file | The shipped `.env.example`, which lists every optional variable. | `.env.example` |
| 🤖 CI | Pinned toolchain, locked builds, format, lint, nextest, docs, and the setup script. | `.github/workflows/ci.yml`, `.config/nextest.toml` |

## 🧪 How it is tested

- **Configuration:** `crates/squad-protocol/tests/config.rs` covers defaults, precedence, roster limits, personas, judge references, and exact diagnostics.
- **CLI configuration and secrets:** `crates/squad-cli/tests/configuration.rs` and `crates/squad-cli/tests/m6_credential_safety.rs` check file and override precedence, malformed files, and credential absence from diagnostics.
- **Setup script:** `crates/squad-cli/tests/m6_setup.rs` and `scripts/test-setup.sh` run the installer with mock tools. They check that the example file is shipped exactly, that existing configuration is preserved, and that `.env` is created with mode `0600`.

## Audit follow-up (2026-11-26)

The audit verified crate licensing and notices, existing judge constants, and the README configuration/dependency documentation. New `foundations_audit.rs` tests in protocol and CLI cover census seed defaults, file/process precedence, exact diagnostics, empty overrides, overflow, fractions and trailing text. The PTY round-trip now verifies debug logging reaches the file and stays out of terminal output. CI now isolates application state and schedules shellcheck plus full fixture-credential setup on both platform matrix entries.
